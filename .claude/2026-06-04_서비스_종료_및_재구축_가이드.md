## 3. AWS 재구축 순서

### 3.1 EC2 인스턴스 생성

**리전**: ap-northeast-2 (서울) 권장 (한국 거래소 API 지연 최소화)

```
1. EC2 콘솔 접속
2. 인스턴스 시작
   - 이름: jwcoin-trading-bot
   - AMI: Amazon Linux 2023 (ARM)
   - 인스턴스 유형: t4g.nano (월 ~$2.56)
   - 키 페어: 새로 생성 또는 기존 사용
   - 보안 그룹: SSH (22번 포트) - 내 IP만 허용
   - 스토리지: 8GB gp3
```

### 3.2 Elastic IP 할당

```
1. EC2 → 탄력적 IP → 탄력적 IP 주소 할당
2. 생성된 IP 선택 → 작업 → 탄력적 IP 주소 연결
3. 인스턴스 선택 → 연결
4. 이 IP를 Upbit API 허용 IP에 등록
```

### 3.3 서버 환경 설정

```bash
# SSH 접속
ssh -i ~/Downloads/jwcoin-key.pem ec2-user@[ELASTIC_IP]

# 패키지 설치
sudo dnf update -y

# 프로젝트 클론

python3 -m venv venv
```

### 3.5 systemd 서비스 등록

```bash
sudo nano /etc/systemd/system/jwcoin.service
```

```ini
[Unit]
Description=JWCoin Trading Bot
After=network.target

[Service]
Type=simple
User=ec2-user
WorkingDirectory=/home/ec2-user/jwcoin
Environment=PATH=/home/ec2-user/jwcoin/venv/bin
ExecStart=/home/ec2-user/jwcoin/venv/bin/python autotrade_ec2.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable jwcoin
sudo systemctl start jwcoin
```

## 5. 중요 주의사항

### 리전 확인
- 항상 **서울 리전 (ap-northeast-2)** 선택 확인
- 실수로 다른 리전에 만들면 비용 낭비

### API 키 보안
- .env 파일은 절대 git에 커밋하지 않기
- chmod 600 ~/.env 권한 설정

### Upbit API IP 등록
- EC2 Elastic IP를 Upbit API 관리 페이지에 등록 필수
- 등록 안 하면 API 호출 실패
